# Student Management System with Data Persistence

## As an administrative assistant at an educational institution, you need to develop a simple system that allows you to manage basic student information. The system must allow you to register, view, update, and delete students, as well as store the information in a structured way for later use.

## How do I run the code?
The code must be run in an IDE with Python installed, such as Visual Studio Code.

## Functionalities
The code has functionalities such as displaying all registered students, adding a new student, searching for a student, deleting a student, and updating a student's data.

The "display students" functionality shows all registered students with their respective data. Adding a new student prompts the user for the student's first name, last name, age, and program. The functionalities such as searching for a student, deleting a student, and updating student data only require the ID of the student you want to search for to execute the function.
